# Restaurant Menu Page

A responsive restaurant menu website built with **HTML, CSS and JavaScript**.

## Features
- Menu items grouped into categories (Starters, Main Course, Desserts, Drinks)
- Item name, description and price shown on each card
- Category filter buttons built with JavaScript
- Responsive layout for mobile, tablet and desktop
- Menu data stored in one array, so adding a new dish is easy

## Technologies Used
- HTML5 - page structure
- CSS3 - layout (Flexbox, Grid), styling, media queries
- JavaScript - dynamic content and category filtering

## How to Run
1. Download or clone this repository
2. Open `index.html` in any web browser

## Project Structure
```
restaurant-menu/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Add a New Dish
Open `script.js` and add a new line inside the `menuItems` array:
```js
{ name: "Dish Name", category: "main", price: 200, description: "Short description." }
```
